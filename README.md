# Zé Faxina 🧹

Landing page do **Zé Faxina** — serviços de limpeza profissional em São Paulo.

O cliente seleciona o tipo de serviço, o pacote de horas e os extras, e clica no botão para abrir o WhatsApp com uma **mensagem já formatada** — sem precisar de intermediação manual.

## 🚀 Como ativar no GitHub Pages

1. Acesse **Settings** → **Pages** no repositório
2. Em **Source**, selecione a branch `main` e a pasta `/ (root)`
3. Clique em **Save**
4. Aguarde ~1 min e acesse `https://felipeatene.github.io/ze-faxina/`

## 📱 Configurar o número do WhatsApp

Abra `index.html` e localize a linha:

```js
const WHATSAPP_NUMBER = '5511999999999';
```

Substitua pelo seu número real (55 + DDD + número, somente dígitos).

## 🛠️ Serviços configurados

- Apartamento · Casa · Escritório · Pós-obra
- Pacotes: 4h, 6h ou 8h
- Extras: lavar roupa, passar roupa, organizar armários, lavar louça, limpar janelas, área externa
